# Forge

Native iOS training-readiness app. Reads Apple Health data overnight, scores how recovered you are, and recommends today's session through an Activity Advisor.

## What's in the box (v0.1)

- **Readiness score (0-100)** weighted from sleep, HRV, RHR, training load (ACWR) and wrist temperature
- **Transparent breakdown** — every sub-score shows the actual value vs your personal baseline
- **Activity Advisor** — 1-3 ranked recommendations per day, with RPE/duration caps that auto-tighten when ACWR > 1.5 or readiness is depleted for 3+ days
- **Trends tab** — HRV / RHR / load over the last 30 days (Swift Charts)
- **Workouts tab** — last 7 days pulled from HealthKit
- HealthKit auth flow + pull-to-refresh

## First-time setup

You currently have only the Xcode Command Line Tools installed — you need the full Xcode app to build iOS targets.

```bash
# 1. Install Xcode (App Store, ~10 GB) then point xcode-select at it:
sudo xcode-select -s /Applications/Xcode.app/Contents/Developer

# 2. Install XcodeGen (turns project.yml into a real .xcodeproj)
brew install xcodegen

# 3. From this folder:
cd /Users/macbookkacper/Documents/PythonProgramming/Forge
xcodegen generate
open Forge.xcodeproj
```

In Xcode:

1. Select the `Forge` target → **Signing & Capabilities** → pick your **Personal Team** (free Apple ID works).
2. Plug in your iPhone (HealthKit doesn't work on the Simulator — it doesn't have your data).
3. Hit **Run** (⌘R). First launch will ask for Health permissions for sleep, HRV, RHR, wrist temperature, steps, workouts, and active energy.

## Readiness formula

Weights are tuned defaults — edit them in [`ReadinessCalculator.swift`](Forge/Readiness/ReadinessCalculator.swift):

| Signal | Weight | Notes |
|---|---|---|
| Sleep | 30% | Duration + restorative fraction (deep + REM) + efficiency |
| HRV | 25% | Z-score vs 28-day baseline; +1σ ≈ 80/100 |
| Resting HR | 15% | Inverted Z-score vs 28d baseline |
| Training Load (ACWR) | 20% | Sweet spot 0.8-1.3 → 100; >1.5 penalized |
| Wrist Temp | 10% | Apple's overnight deviation from baseline |

Bands: **Prime** 85+ · **Ready** 70-84 · **Moderate** 55-69 · **Low** 40-54 · **Depleted** <40.

## Activity Advisor logic

Lives in [`ActivityAdvisor.swift`](Forge/Advisor/ActivityAdvisor.swift). Two layers:

1. **Caps** — every band gets a max RPE and max minutes. ACWR > 1.5 trims max RPE to 7. 3+ consecutive low days forbids hard work entirely (forces a mobility swap).
2. **Recommendations** — branched on band × yesterday's session. Alternates modalities (lift yesterday → run today, ran hard yesterday → heavy lift today). Suggests a long run if you haven't done one in 7 days and today is Sunday.

## Next features (roadmap)

- In-app lifting logger writing back to HealthKit (sets/reps/RPE, per-muscle-group fatigue model)
- Subjective morning check-in (soreness/mood/stress sliders) blended into readiness
- WidgetKit small/medium/large + lock screen circular

## Notes

- This is a personal tool, not a medical device. Don't use it to make clinical decisions.
- All processing is on-device. Health data never leaves your phone.
- HealthKit's strength-training data is thin (no sets/reps) — that's why the lifting logger is on the roadmap as the next big chunk.
